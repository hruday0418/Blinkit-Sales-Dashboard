# Blinkit Sales & Operations Dashboard

## Overview
An interactive Power BI dashboard analyzing 5,000+ records of Blinkit 
grocery delivery data to uncover sales trends, outlet performance, 
and product-level insights.

## Tools Used
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query

## Key Features
- KPI cards for Total Sales, Average Rating, and Item Visibility
- Dynamic filtering by Outlet Size, Location Tier, and Item Category
- Bar charts, Donut charts, and Slicers for interactive exploration

## Key Insights
- Identified sales trends across Tier 1, Tier 2, and Tier 3 city outlets
- Created DAX calculated measures for advanced reporting
- Performed data cleaning to ensure data quality and accuracy
